# Ling's Cars — Landing Page Redesign

A redesign of the Ling's Cars car-leasing homepage, built with plain HTML and CSS.

## Sections

1. Hero with a main call-to-action and three information cards
2. Browse Cars with horizontally scrollable car cards
3. Why Choose LINGsCARS with scrollable feature cards
4. FAQ with four numbered questions
5. Customer reviews
6. Footer with link columns
